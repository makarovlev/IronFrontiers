# Iron Frontiers

Плагин захвата территорий для RPG-сервера GachiCraft.

## Технический стек

- Java 21
- Maven 3.9+
- Paper API 1.20.6 (совместимость с Purpur 1.20.6)
- MySQL/MariaDB

Проект находится на этапе начальной инициализации. План разработки и критерии приёмки будут храниться в `docs/PLAN.txt`.
