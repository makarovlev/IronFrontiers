# Локальная среда разработки

## Требования

- JDK 21 (не JDK 17/22)
- Maven 3.9+
- Purpur 1.20.6 для ручной проверки
- MySQL 8 / совместимая MariaDB
- PrivateMobsX и дополнительные плагины только для нужных интеграционных сценариев

## Сборка

```bash
mvn -B verify
```

Версию Java проверяет Maven Enforcer Plugin.

## Сервер

1. Создать отдельную тестовую директорию и запустить Purpur 1.20.6 с Java 21.
2. Установить PrivateMobsX и внешние плагины для проверяемого сценария.
3. Создать отдельную тестовую БД и пользователя с правами только на неё.
4. Запустить Iron Frontiers один раз для создания YAML-файлов.
5. Указать настройки БД в локальном config.yml.
6. Не коммитить пароли, конфиги с секретами и файлы мира.

## Карта

Трансформацию блоков/биомов проверять только на копии war world. Пока карта не передана, геометрия, KPM и автомат состояний покрываются unit-тестами.
