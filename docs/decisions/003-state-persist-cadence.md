# Решение 003 — независимый интервал периодического сохранения состояний

Дата: 2026-11-27

## Наблюдение

Раздел 2.6 требует сохранять остатки состояний каждые `state_persist_interval_seconds`. Раздел 9.3 отдельно задаёт период KPM-снимков/тика автомата (`kpm.update_interval_seconds`). Если сохранять только в KPM tick, увеличение KPM interval до 60 секунд нарушит заданный десятисекундный интервал persistence.

## Решение

Использовать два ключа в `CentralTimerScheduler`:
- `sector-automaton-tick` с периодом `kpm.update_interval_seconds`;
- `sector-state-persist` с независимым периодом `state_persist_interval_seconds`.

Оба таймера исполняются одним центральным Bukkit ticker. Изменение любого интервала через `/if reload` пересоздаёт только соответствующий timer.

## Причина

Соблюдается период записи БД независимо от скорости реакции автомата, не добавляя отдельный Bukkit task или поток.
