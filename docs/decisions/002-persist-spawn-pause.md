# Решение 002 — персистентность spawn_pause_left_s

Дата: 2026-11-27

## Наблюдение

Раздел 10 определяет spawn_pause_left_s как остаток секунд после захвата, а раздел 10.5 требует сохранять остатки таймеров, чтобы простой выключенного сервера не съедал их. Ориентировочная схема if_sector_state в 17.2 перечисляет основные таймеры, но не включает spawn_pause_left_s.

## Решение

Добавить spawn_pause_left_s в if_sector_state отдельной versioned migration 2. Сохранять его вместе с остальными остатками таймеров.

## Причина

Без этого столбца рестарт во время паузы после захвата преждевременно разрешал бы новые спавны. Отдельная миграция сохраняет совместимость уже работающей схемы версии 1; существующие записи получают значение 0 по умолчанию.
