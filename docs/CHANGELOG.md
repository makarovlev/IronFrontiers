## [0.3.0-stage3a] — 2026-11-28

### Добавлено
- SelectionManager: инструмент с PDC-меткой, одна сессия на администратора, добавление вершин, Shift+ПКМ для отмены последней, закрытие по клику на первую вершину, валидация осевых контуров и предпросмотр DUST по поверхности.
- Атомарное текстовое добавление сектора в sectors.yml с сохранением существующих комментариев; новый сектор сразу регистрируется в памяти как ENEMY и сохраняется в MySQL.
- Административные команды /if sectors list, info, tp, show, create, delete, set; строки списка кликабельны, добавлены источники порогов/таймеров и сведения о настройках форпоста.
- /if agree и чат-подтверждение agree с персональным тайм-аутом.
- Удаление сектора очищает MySQL state/override, KPM-снимки и runtime; очередь асинхронных записей синхронизируется с удалением.
- В конфиге нового сектора выводятся закомментированные примеры дополнительных параметров.

### Исправлено
- Сравнение вложенных YAML-разделов при /if reload: одинаковые replaces больше не выдаются за изменённые из-за сравнения объектов ConfigurationSection по identity.
- Сообщения о захвате, разрушении и потере сектора рассылаются всем онлайн-игрокам сервера, независимо от мира.
- Удаление сектора сначала атомарно обновляет YAML, затем удаляет DB-записи; ошибка записи файла не уничтожает старое runtime/DB-состояние.
- Предпросмотр длинных рёбер ограничивает перебор клетками в радиусе игрока; линейный контур не рисует закрывающий дублирующий отрезок.
- Подтверждено: KPM-порог хранится в десятых долях (5.0 → 50); это штатный формат БД.

### Пока не входит в Stage 3A
- Реальный спавн кластеров и интеграция PrivateMobsX API — Stage 3B.
- Применение replaces, преобразование биомов/блоков, журнал и откат мира — Stage 3C.
- Ручная приёмка на Purpur 1.20.6 остаётся за владельцем сервера.

# Changelog

## [0.2.0-stage2] — 2026-11-27

### Добавлено
- Геометрия XZ без Bukkit: проверка осевых контуров, растеризация scanline с включённой границей, линии, вогнутые фигуры, интервалы строк и объединение в прямоугольники.
- Primitive-long ChunkIndex с четырьмя long-масками на чанк, O(1) `sectorAt`, `sectorsNear`, площадь и дистанция до сектора.
- Загрузчик `sectors.yml`, независимая валидация секторов и spawn anchors, immutable SectorRegistry, SurfaceResolver без принудительной загрузки чанков.
- Скользящие окна KPM в десятых долях, персональные окна, immutable snapshots, idle cleanup и безопасное изменение размера окна.
- Чистый Java автомат ENEMY/SAFE/HELD/DESTRUCTION с остатками таймеров, startup grace, freeze_when_empty, infinite_safe, occupation, anti-flap и resume window.
- Bukkit events и batch сообщения о начале разрушения/потере нескольких секторов.
- Миграция v2: `spawn_pause_left_s` и таблица `if_sector_override`; загрузка и сохранение состояния сектора/override.
- Независимый от частоты KPM-тиков периодический persist; финальная запись состояния ожидается до закрытия MySQL при выключении.
- Debug-команды `/if debug kill`, `/if debug state` и персистентные overrides `/if sectors set`.
- JUnit 5 тесты геометрии, KPM и автомата состояний.

### Проверка
- GitHub Actions run #36: `mvn -B verify` — success.
- Ручная приёмка Stage 2 на Purpur 1.20.6 и Spark-профилирование ещё не выполнены.

### Границы этапа
- `MobSpawn` остаётся заглушкой; настоящие кластеры, FormationCalculator, SpawnDirector и интеграция PrivateMobsX API будут на этапе 3B.
- Административные команды выделения/просмотра/удаления и трансформация мира остаются на этапах 3A/3C.
