# Сценарии тестирования

## Этап 1 — основа проекта

1. Собрать на JDK 21 командой `mvn -B verify`. Ожидание: оба модуля собираются, unit-тесты проходят.
2. Запустить Purpur 1.20.6 с PrivateMobsX. Ожидание: IronFrontiers создаёт config.yml, messages.yml, sectors.yml, mobs.yml, blueprints.yml и menus.yml.
3. Настроить тестовую MySQL и запустить сервер. Ожидание: HikariCP подключается, создаются таблица версии схемы и таблица состояния секторов.
4. Повторить с недоступной БД. Ожидание: SEVERE с понятной причиной, механики секторов не запускаются, команда доступна в деградированном режиме.
5. Изменить обычную настройку и выполнить `/if reload`. Ожидание: параметр перечитан.
6. Изменить database.host или multiserver.enabled без рестарта и выполнить `/if reload`. Ожидание: путь показан как требующий рестарта, старое значение остаётся активным.
7. Запускать без каждого softdepend. Ожидание: WARNING об отсутствующей интеграции, основной плагин не отключается.
8. При multiserver.enabled=false убедиться, что Redis executor/соединение не создаются.
9. Проверить YamlTextEditor: append сохраняет комментарии, duplicate id отклоняется, remove удаляет только выбранный блок.
